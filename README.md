# 和風字旅｜尋回失落的言葉

日式國風潑墨與 Q 版旅人包裝的日語學習網站。從五十音暖身出發，與空、燈、蓮及白狐穿過五座國度，學習 N5 到 N1 社群參考詞彙，完成英雄之旅。

**正式網站：https://nihongo-odyssey.hk6429.workers.dev/**

## 執行

需要 Node.js 22 以上，無套件安裝步驟。

```sh
npm start
```

網址 http://localhost:8793/ 。伺服器僅監聽本機，不等於公開部署。`PORT` 環境變數可指定其他連接埠。原英文字旅專案未變更。

## 部署

使用 Cloudflare Workers Static Assets，設定在 `wrangler.jsonc`。需先安裝 Wrangler 並完成 Cloudflare 登入。

```sh
npm test
wrangler whoami
wrangler deploy --dry-run
wrangler deploy
```

Wrangler 自動執行 `npm run build`，只將指定的網站檔案、圖片、詞庫與來源授權說明複製到 `dist/`。原始 CSV、測試存檔及開發文件不會上傳；不存在的網址回傳 404。

公開網址與本機網址的瀏覽器存檔互相獨立。搬移進度時，先在原網址匯出備份，再到公開網址匯入。

## 課程與故事

| 國度 | 分級 | 唯一詞條 |
|---|---|---:|
| 花見里 | N5 | 805 |
| 潮見港 | N4 | 755 |
| 霧森 | N3 | 1,813 |
| 月影都 | N2 | 3,212 |
| 墨源山 | N1 | 4,044 |
| 合計 | | 10,629 |

- 25 章原創故事、75 組日中對照段落、三種角色視角、50 個選項；每次選擇具有立即結果、下一章回聲與結局回收。
- 全詞庫分成 2,127 個最多五詞的任務；看詞卡後練習辨義／聽辨與假名回想。答錯重排，整組完成才記入進度。
- 章節詞彙完成後，需通過閱讀理解才能繼續主線。第五印在 N1-4 形成，N1-5 保留返鄉結局。
- 可自由篩選任一等級與搜尋日文、假名、中文，不必先解鎖主線。辭典瀏覽不算完成課程。
- 平／片假名參考表、固定五題清音暖身、畫面上的假名小鍵盤。暖身可跳過。
- 複習：滿一天的已學詞，最多五詞排入新任務；手動複習沒有到期詞時，練最近五詞。不是完整 FSRS 排程。

## 朗讀

所有詞條的假名、來源提供的例句／語例、故事日文段落與對話都能朗讀；提供慢速與停止。長文逐句排程，停止或離開後不續播。

使用裝置 `ja` 日語聲線，優先選 Kyoko／Otoya 等匹配名稱；沒有時使用其他可用日語聲線，完全沒有則顯示提示並維持文字流程。聽辨題可以切換文字題。沒有內建 MP3、不需付費 TTS API；是否需要網路取決於裝置聲線。

## 進度與隱私

- 新版使用 `nihongo-odyssey-v2` localStorage，保留原 `nihongo-odyssey-v1` 存檔，未把舊版 100 詞錯當新課程進度。
- `?test=1` 使用隔離測試鍵，不寫入一般旅程。
- 支援 JSON 備份匯出／匯入。匯入前驗證版本、角色、章節次序、抉擇、複習資料，並確認取代。
- Web Locks 可用時序列化同來源分頁的寫入；已完成任務重複送出不會重複計分。舊章答案不能套到新章。
- 尚無帳號登入或跨裝置雲端同步。清除網站資料會移除進度；下載備份可保留資料。
- 使用者能修改本機存檔；本站不是防作弊或正式評分系統。

## 驗證

```sh
npm test
python3 scripts/import-vocabulary.py --check
node scripts/simulate-journey.mjs
```

- 自動測試包括資料覆蓋、全課程通關、存檔重載、章節門檻、錯題重排、同音選項、同義提示、合法讀法、跨章舊答案防護及語音佇列。
- 完整程式模擬：10,629 詞、2,127 任務、25 章、25 次抉擇，詳見 [通關輸出](docs/journey-verification.json)。
- 瀏覽器抽測從選角到首個任務、備份匯入、末章考驗與結局，以及手機排版；[驗證與交接](docs/HANDOFF.md) 說明範圍。

## 限制

資料及故事未經日語教師逐條審定。日文難度逐級增加，但不是正式分級認證。程式通關不是真人學習成效；未對一萬餘詞逐一人工聽審。此版沒有完整文法、作文與口說課程。公開部署的檔案指紋與瀏覽器抽測見 [正式站驗證](docs/production-readback.json)。
