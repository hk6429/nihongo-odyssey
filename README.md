# 和風字旅 Nihongo Odyssey

零基礎日語旅行學習的第一版可玩原型。從五十音暖身出發，也可直接跳過暖身，前往十站小鎮旅行。介面採台灣繁體中文，教材保留日文原文。

## 執行

需要 Node.js 22 以上，不需要安裝套件。

```sh
npm start
```

開啟 http://localhost:8793 。使用 `PORT` 環境變數可指定其他連接埠。伺服器僅監聽本機回環位址，只提供五個公開前端檔案。

## 學習流程

- 十個場景、100 個唯一詞條、100 組自編例句及中譯；每站兩個五詞任務。
- 五十音頁含平假名／片假名清音、濁音、半濁音，拼音可隱藏；附長音、促音、拗音、撥音簡介及五題固定清音暖身。
- 五張詞卡之後，分別練習辨義與從中文回想假名；接受等價平／片假名及半形片假名，答錯重排。
- 學習卡提供朗讀及慢速朗讀；裝置必須有 `ja` 日語聲線，缺少時顯示提示，不擅自改用其他語言聲線。
- 完成整個任務才取得五詞與 50 XP；未完成的任務離開後重新開始。
- 學過的詞滿一天後，最多五詞排入下次任務。手動複習沒有到期詞時練習最近五詞。複習不加 XP。
- 已完成關卡可開啟單字行囊。學過不代表熟練，不以 XP 宣稱學習成效。

## 儲存與隱私

使用瀏覽器 localStorage，鍵名 `nihongo-odyssey-v1`。`?test=1` 使用隔離的測試鍵名，不污染一般旅程。沒有帳號、Google 登入或雲端同步；不同裝置、瀏覽器及來源網址的紀錄不共用。清除網站資料會移除紀錄。

可下載 JSON 旅程備份；第一版尚無匯入介面。儲存失敗時會提示並提供重試。讀入資料限制版本、任務數及複習時間；進度可被本機使用者修改，不適合作為正式評分或防作弊依據。

多分頁會接收進度更新，完成任務前會讀取最新資料，重複完成同一任務不會再次加分。未使用跨分頁鎖，不承諾高度同時寫入時完整保留所有複習時間。

## 檔案

- `data.js`：原創教材與五十音資料。
- `engine.js`：任務佇列、假名正規化、存檔及複習。
- `app.js`、`style.css`、`index.html`：無框架前端與原創 SVG 車站插畫。
- `server.mjs`：零相依本機預覽伺服器。
- `tests/engine.test.js`：教材結構及學習流程測試。
- `docs/HANDOFF.md`：本次里程碑、驗證與後續工作。

## 驗證

```sh
npm test
```

七項自動測試涵蓋全部二十個任務、錯題重排、假名等價、損壞存檔、複習與重複提交。UI 檢查另見交接文件。

## 教材與範圍

詞表、例句、中譯與 SVG 插畫為本專案自編，未複製既有字旅的語料、音檔、帳號或金鑰。參考英文字旅的旅行／小任務／行囊概念，日語引擎獨立實作。不是官方 JLPT 指定詞表，也不是完整五十音課程；固定五題不能作為五十音精熟診斷。

目前提供辨義、假名回想和發音參考，尚未提供純聽辨測驗、造句、語法課程、角色分支或十站獨立插圖。尚未經日語教師全面審訂或真人學習成效驗證。網站未部署公開主機；GitHub 程式庫不等於網站上線。
