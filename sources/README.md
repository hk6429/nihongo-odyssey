# 詞彙來源與重建

此資料夾保留未經修改的上游文字來源及固定版本清單。未下載音檔，未執行上游程式。

使用 Python 3 標準函式庫即可重建，沒有額外套件或金鑰需求。在專案根目錄執行：

```sh
python3 scripts/import-vocabulary.py
python3 scripts/import-vocabulary.py --check
```

來源檔案缺少時，可用 `python3 scripts/import-vocabulary.py --download` 補下載；只有符合固定 SHA-256 的內容才會寫入。既存來源若被修改會直接失敗，避免不知情地改用不同版本。`--check` 會驗證來源與資料欄位，重新生成並逐位元組比對兩份產物。

輸出包含 `data/vocabulary.json` 和 `docs/vocabulary-audit.json`。後者記錄原始／唯一筆數、各級筆數、全部重複、各來源級別、缺少例句、外來語讀音修正、同形異讀、來源與產物 SHA-256。

資料處理規則：

1. 讀取 39 欄、Tab 分隔的上游 Anki 文字檔；欄位宣告、來源識別碼、必填欄位均須通過檢查。
2. 專取繁體中文釋義與繁體中文例句翻譯。日文保留原字形，不以中文字體轉換改寫。
3. 將 HTML 解碼為純文字，移除不可見內容、音檔標記、詞形中的 Anki 注音與注音間隔。
4. 外來語的讀音欄位若為英文等詞源，改用已是純假名的詞形；其餘不能判定的讀音一律報錯。
5. 以正規化後的詞形及讀音去重。同形異讀保留；同形同讀合併不同釋義，歸入最低難度（N5 最易），記錄每筆來源級別及識別碼。
6. 選取第一個例句／用語示例及其配對翻譯。只有關聯詞或反義詞的筆記不冒充例句，兩個欄位留空。
7. 級別依上游標籤，並和牌組分類交叉檢查；原始列號及重複清單供追溯。識別碼由 `word + NUL + kana` 的 SHA-256 前 20 碼產生，級別變動不會改變識別碼。

這是完整匯入指定來源版本的社群參考資料，並非「JLPT 官方完整詞庫」。原始來源不宣稱無誤，產物也不代表已逐筆經教師審定。
