# 和風字旅｜尋回失落的言葉

日式潑墨與 Q 版旅人陪伴的日語學習網站。從五十音入門、情境主線到 N5～N1 擴充詞彙，以實際使用日語推進故事。

**正式網站：https://nihongo-odyssey.hk6429.workers.dev/**

## 執行與部署

需要 Node.js 22 以上，無套件安裝步驟。

```sh
npm start
```

本機 http://localhost:8793/；`PORT` 可指定其他連接埠。Cloudflare Workers Static Assets 設定在 `wrangler.jsonc`，需已安裝 Wrangler 並登入。

```sh
npm test
wrangler whoami
wrangler deploy --dry-run
wrangler deploy
```

建置白名單只複製網站程式、教材、圖片、來源授權；不發布原始 CSV、測試備份或開發文件。不存在網址回傳 404。

## 兩種學習路線

- **情境主線**：五國、25章。每章具有Can-do目標、句型、10個核心詞、兩組五詞練習；每組後展開微劇情，再完成3題新日語情境考驗。
- **擴充練習**：完整10,629唯一詞保留，每級都能直接練五詞，不需先完成低級主線。查詞本身不計進度。
- **自主程度起點**：可直接從N5～N1開始。略過的章節另標，不計完成；返回低級時保留已完成詞與新考驗紀錄。這不是程度認證。
- **角色與選擇**：空、燈、蓮提供不同觀察；observe/help兩種抉擇具有不同微劇情和情境題。主線仍是25章共用世界，不是無限分支遊戲。
- **情境詞與來源級別分開**：核心詞依當章需要選配，可能跨級複現；分級是社群參考，非官方指定詞表。

## 從假名到運用

- 假名分行、平／片假名、清濁半濁音、長音／促音／拗音。依序示範、辨讀、拼排、撤提示回想；可隨時跳過，不將一次完成宣稱為精熟。
- 保留假名單元、首答、提示與弱項；沒有日語聲線時明示文字替代。
- 故事有關鍵詞振假名、點查讀音與意思、中譯顯示切換。N5提供較完整的生詞支援，不宣稱所有級別逐字標音。
- 詞彙包含辨義／聽辨、假名回想；可用小鍵盤、完整提示或先拼排再回想。提示會留證據，不當無提示答對。
- 章末改用新材料的閱讀、聽解與回應選擇題；作答前不顯示中譯，作答後提供解說。無聲線或自行切換文字會另記。
- 情境題仍是固定選擇題，尚不是自由口說評量、作文或完整文法課程。

## 複習與學習證據

- 到期詞依最久未複習順序安排，避免每天一組反覆抽到前五詞；每次最多五個舊詞，混合意思與假名回想。
- 分開顯示完成詞數、首次無提示答對、隔日無提示答對、待複習數。
- 首次無提示：初次詞彙任務的意思／聽辨與假名題都一次正確且未看提示。
- 隔日保留：距上次接觸至少24小時，該詞本次複習首次無提示正確。它是一次表現紀錄，不等於永久熟練。
- 每次作答、提示與文字替代會保存未完成證據，中途離開不會把首答錯誤洗掉；整組完成才增加完成詞數。
- 狀態不具防作弊保障，不能當正式評分系統。沒有經實證校準的自適應難度或完整FSRS排程。

## 存檔與語音

- v3使用獨立localStorage鍵，保留v2原鍵；支援v2遷移、v3備份匯出／匯入。壓縮儲存降低完整詞庫超額風險，匯出保留可讀JSON。
- 舊完成詞與故事紀錄保留，首次正確與新情境考驗不補造。舊版已清章仍可重做新版情境任務。
- 嚴格驗證匯入、Web Locks序列化、重複提交去重、切換起點後拒絕舊任務提交。
- `?test=1`用隔離測試鍵；本機與正式網址的進度分開，可透過匯出／匯入搬移。未提供帳號與跨裝置同步。
- 使用裝置日語TTS，優先匹配Kyoko／Otoya等聲線；長文分句、支援慢速與停止。沒有日語聲線可使用文字流程；不是本站錄製音檔，未逐詞人工聽審。

## 教材、來源與限制

詞彙來源 egg rolls，繁中 ShihHsing Chen，固定來源版本及SHA見 [來源紀錄](sources/README.md)。原始10,641筆去重為10,629詞，原始詞庫不直接改寫。

[data/vocabulary-overrides.json](data/vocabulary-overrides.json)是可追溯補充層：補齊122個原先缺例句詞的原創例句，修正抽查發現的語義、語用及中文錯字。原始來源的其他語例有些是短語，不宣稱全庫都有完整句子。故事亦校正搭配與回聲時機。[教材修正紀錄](docs/content-corrections.md)

第三方詞庫為 **CC BY-NC 4.0**，非商用，保留作者、來源與改作標示。程式、原創故事及補充例句不會改變原詞庫授權。[完整聲明](THIRD-PARTY-NOTICES.md)

本版修正的是四角色模擬評估發現的問題；不是四位真人審定，也尚未有真人前後測／延宕測驗。詞庫與故事未經真人日語教師逐條審核；通關或完成詞量不代表JLPT成績。

## 選擇題鍵盤操作

A：← 或 1；B：↑ 或 2；C：↓ 或 3；D：→ 或 4。依畫面選項順序作答；題目未提供的選項不接受按鍵。答對直接進入下一題或完成畫面，答錯停留解析，讀完再按繼續。輸入框、選單、中文／日文輸入法組字與系統快捷鍵不攔截；長按與雙擊不連續作答。
